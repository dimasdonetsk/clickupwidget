# ClickUp Widget для Mac

Та сама програма, що й на Windows: панель задач на робочому столі, тихе віконце оновлень, картка «Зараз», коментарі з @згадками, таймер і статуси одним кліком. Інтерфейс — на Avalonia (`mac/`), уся логіка — спільна з Windows (`core/`).

## Поставити

1. Завантаж пакет:
   - поки маківських пакетів немає в релізі — GitHub → **Actions → macOS** → остання зелена збірка → унизу **Artifacts** → `ClickUpWidget-mac-<версія>` (потрібен вхід у GitHub), розпакуй;
   - коли їх додано до релізу — зі сторінки [останнього релізу](https://github.com/dimasdonetsk/clickupwidget/releases/latest).
2. Обери файл під свій Мак ( → «Про цей Mac»):
   - **Чип Apple M1…M4** → `ClickUpWidget-osx-arm64-Setup.pkg`;
   - **Процесор Intel** → `ClickUpWidget-osx-x64-Setup.pkg`.
3. Програма не підписана Apple Developer ID, тож перший раз macOS її заблокує:
   - відкрий `.pkg` → «Не вдалося перевірити…» → **Готово**;
   - **Системні параметри → Приватність і безпека** → унизу «…pkg заблоковано» → **Все одно відкрити** → пароль;
   - інсталятор поставить «ClickUp Widget» у «Програми» і запустить його.

   Інший шлях — портативний `ClickUpWidget-osx-…-Portable.zip`: розпакуй, перенеси в «Програми» і один раз виконай у Терміналі
   ```bash
   xattr -dr com.apple.quarantine "/Applications/ClickUp Widget.app"
   ```
4. Віджет попросить особистий API-токен ClickUp: **аватар унизу зліва → Settings → Apps → API Token → Generate / Copy**. Встав його у вікно — готово.

## Що де на Маку

- **Панель і віконце оновлень** лежать на робочому столі: над іконками, під усіма вікнами, на всіх робочих столах (Spaces); Mission Control їх не розсуває. Перетягуються за шапку, положення запам'ятовується.
- **Значок у рядку меню** (угорі праворуч) відкриває меню: «Задачі зараз…» — картка з таймером і задачами на сьогодні; запущений таймер видно й можна зупинити просто з меню; далі ті самі пункти, що в меню трею на Windows («Що показувати», тема, автозапуск…).
- **⋯ або правий клік (Ctrl+клік)** у панелі, картці чи інбоксі — те саме меню. Галочки «Що показувати» не закривають меню.
- У Dock і в Cmd+Tab віджета немає — він живе на столі й у рядку меню.
- **Токен** лежить у Keychain («Зв'язка ключів»), запис «ClickUp Widget». У файлах налаштувань його немає.
- **Автозапуск** — LaunchAgent `~/Library/LaunchAgents/com.dimasdonetsk.clickupwidget.plist`; вимикається в меню («Запускати при вході»). macOS може показати сповіщення «Додано об'єкт входу» — це він.
- **Налаштування, інбокс і журнал** — `~/Library/Application Support/ClickUpWidget` (`log.txt` — перше, що дивитись при багах). Меню → «Відкрити папку налаштувань».
- **Оновлення** — тихо, двічі на день, як на Windows, щойно маківські пакети нової версії є в релізі GitHub.

## Перевірити на Маку (чекліст)

1. Встановлюється й запускається; у рядку меню є значок, у Dock — немає.
2. Токен приймається; після «Вийти» і повторного запуску токен не питає (Keychain).
3. Панель під усіма вікнами: відкрий будь-яке вікно поверх — панель під ним; перейди на інший робочий стіл (Ctrl+→) — панель там теж.
4. Перетягни панель за шапку, вийди й запусти знову — стоїть там само.
5. Наведи на задачу: кнопки коментаря, статусу й таймера; таймер запускається й зупиняється, статус змінюється.
6. Коментар: кнопка коментаря → поле під рядком, у нього можна одразу друкувати; `@` показує людей; Enter надсилає, Esc закриває.
7. Меню значка → «Задачі зараз…» → картка під рядком меню; клік деінде — закривається.
8. ⋯ / правий клік → меню; кілька галочок «Що показувати» підряд, меню не закривається.
9. «Запускати при вході»: вийди з облікового запису й зайди — віджет стартує сам.
10. Тема: меню → Тема → Світла / Темна.

Щось не так — надішли `log.txt` з теки налаштувань.

## Збірка

- Кожен push у гілку `macos` збирає Mac-версію на GitHub Actions (`.github/workflows/macos.yml`, `macos-latest`): тести спільної логіки → `ClickUp Widget.app` для Apple Silicon та Intel → пакети Velopack (`.pkg`, `.zip`) → самоперевірка Keychain і автозапуску → знімки вікон з демо-даними (артефакт `screenshots-mac-…`).
- **Випустити для Mac** (щоб встановлені копії оновились): після того як вийшов Windows-реліз версії, **Actions → macOS → Run workflow** (гілка `main`) → поставити **publish**. Маківські пакети додадуться до того самого релізу; Windows-оновлення це не зачіпає (окремі канали `osx-arm64` / `osx-x64`).
- Локально на Маку: .NET 8 SDK, `dotnet tool install -g vpk --version 1.2.161`, потім `bash mac/build-mac.sh osx-arm64`.
- Перевірити вигляд без Мака (і без ClickUp): `dotnet run --project mac -- --demo` (зразкові задачі; справжні налаштування не чіпаються). `--screenshot ТЕКА` зберігає PNG вікон, `--light` — світла тема, `--selftest` — Keychain і автозапуск.

## Обмеження

- Без підпису Apple: перший запуск — через «Все одно відкрити». З Apple Developer ID ($99/рік) можна додати підпис і нотаризацію в `mac/build-mac.sh` (`vpk pack --signAppIdentity … --notaryProfile …`).
- Клік по значку в рядку меню відкриває меню, а не одразу картку: Avalonia на macOS не повідомляє про окремий клік по значку.
- Windows-версія поки працює на своєму `src/AppController.cs`, Mac — на спільному `core/Shared/WidgetController.cs` з тією самою логікою. Нові функції поки треба додавати в обидва, доки Windows не переведено на спільний контролер.
