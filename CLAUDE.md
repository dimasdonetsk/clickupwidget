# ClickUp Widget — пам'ятка для Claude

WPF / .NET 8 програма для Windows: спокійний дашборд задач ClickUp. Автор — Діма (пише українською, коротко; інтерфейс і коментарі в коді — українською).

## Структура
- `src/AppController.cs` — мозок: дані з ClickUp, оновлення вікон, інбокс, коментарі, автооновлення.
- `src/ClickUpClient.cs` — мінімальний клієнт ClickUp API v2 (токен користувача, DPAPI).
- `src/Model.cs`, `src/Inbox.cs`, `src/CommentText.cs` — чиста логіка без вікон (покрита тестами).
- `src/PanelWindow` (панель на столі), `FlyoutWindow` (картка з трею), `InboxWindow` (тихий інбокс), `TasksView` (спільний список задач), `CommentBox` (поле коментаря з @згадками), `TrayController` (меню «Що показувати» тощо).
- `DesktopPin.cs` — вікна під усіма іншими (Progman + HWND_BOTTOM).
- `tests/ClickUpWidget.Tests` — xunit.

## Збірка й реліз
- Локально: `dotnet build src/ClickUpWidget.csproj`, тести: `dotnet test tests/ClickUpWidget.Tests`.
- Push у `main` → GitHub Actions; нова `<Version>` у csproj → реліз з інсталятором (Velopack), встановлені копії оновлюються самі.
- Налаштування, стан інбоксу й журнал: `%AppData%\ClickUpWidget` (`log.txt` — перше, що дивитись при багах).

## Побажання користувача
- Без перевантаження і без «червоних» акцентів; дедлайни не підсвічувати.
- Беклог і скасовані за замовчуванням сховані; усе налаштовується в меню «Що показувати».
- Інтерфейс не повинен стрибати при наведенні; меню не вилазять на сусідній монітор.
- Призначення в інбоксі за замовчуванням вимкнені.

## Стан: гілка `wip-0.4` (НЕ перевірено, ще не збиралось)
Що зроблено в коді:
1. Інбокс — усі типи подій: коментарі, згадки мене (@), мої коментарі, статуси, закриті/видалені, дедлайн, пріоритет, перейменування, призначення, мене прибрали, інші виконавці. Кожен тип вмикається в «Що показувати → Віконце оновлень». Старий `inbox.json` мігрує тихо (`SeenTask.Full`).
2. Коментарі: кнопка при наведенні на задачу (панель/трей) і «Відповісти»/«Коментар» в інбоксі; поле відкривається в тому ж вікні під рядком; `@` показує список людей (учасники задачі першими), Enter — надіслати, Shift+Enter — новий рядок, Esc — закрити. Поки поле відкрите, списки не перебудовуються.
3. Тихе автооновлення двічі на день (`WaitExitThenApplyUpdates(silent: true)`), відкладається, якщо людина пише коментар.
4. У рядку задачі опційно: мітка проєкту, дедлайн, прапорець пріоритету.
